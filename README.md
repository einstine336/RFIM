# RFIM

**Robust Feature Interaction Modulation**

RFIM is a research project on **language-guided 3D affordance prediction** under non-ideal point-cloud conditions.

The approach uses two complementary components:

- **RFC — Reliability-aware Feature Calibration:** regulates point contributions during feature interaction using learned features and local geometric cues.
- **CFE — Context-aware Feature Enhancement:** aggregates relevant information from other visible points to supplement local context.

**Status:** Work in progress. Paper and code will be made available after release.
